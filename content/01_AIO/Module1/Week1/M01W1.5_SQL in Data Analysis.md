## 2.1. Create Database
Cách tạo một Database
```SQL
CREATE DATABASE databasename;
```
Cách xóa Database
```SQL
DROP DATABASE databasename;
```
  
Ví dụ: Tạo ShoppingDB
```SQL
DROP DATABASE IF EXISTS ShoppingDB;
CREATE DATABASE ShoppingDB;
```
→ DROP IF để xóa bản đã tạo ở trước
## 2.2. Create Table
Cấu trúc:
```SQL
CREATE TABLE table_name (
	columnID datatype PRIMARY KEY,
	column2 datatype,
	column3 datatype,
	.....
);
	
```
Vd:
```SQL
USE ShoppingDB;
CREATE TABLE table_name (
	CustomerID INT auto_increment primary key,
	FirstName varchar(50),
	LastName varchar(50),
	Email varchar(100),
    Phone varchar(15)
);
```
Lưu ý: Phải có `USE Database`
