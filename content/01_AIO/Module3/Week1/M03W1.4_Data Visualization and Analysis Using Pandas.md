# I. Series in Pandas
**Nhắc lại: Series** là một cấu trúc dữ liệu 1 chiều, có thể lưu trữ bất kỳ kiểu dữ liệu nào (số, chuỗi, đối tượng Python...). Mỗi phần tử trong Series có một **index** (chỉ mục) và một **value** (giá trị). Ngoài ra, Series còn có thể có **tên** để mô tả nội dung dữ liệu.
## 1. Simple functions
### Create a series
**Tạo danh sách số nguyên:**
Ví dụ dưới đây tạo một Series tên là `num_dropped` từ danh sách `[5, 7, 5, 1, 6]`:
```Python
import pandas as pd
data = pd.Series([5, 7, 5, 1, 6], name='num_dropped')
```
Kết quả:
|Index|Value|
|---|---|
|0|5|
|1|7|
|2|5|
|3|1|
|4|6|
- **data.name**: `'num_dropped'`
- **data.index**: `RangeIndex(start=0, stop=5, step=1)`
- **data.values**: `array([5, 7, 5, 1, 6])`
Khi không truyền `index`, Pandas sẽ tự tạo chỉ mục mặc định từ `0` đến `n-1`.
---
**Tạo Series với index tùy chỉnh:**
Ví dụ tạo một Series chứa tên các ngôn ngữ lập trình, gắn index theo ký tự viết tắt:
```Python
import pandas as pd
data = pd.Series(
    ['C++', 'Golang', 'Java', 'Python', 'Swift'],
    index=list('CGJPS'),
    name='Programming Language'
)
```
Kết quả:
|Index|Value|
|---|---|
|C|C++|
|G|Golang|
|J|Java|
|P|Python|
|S|Swift|
- **data.name**: `'Programming Language'`
- **data.index**: `Index(['C', 'G', 'J', 'P', 'S'])`
- **data.values**: `array(['C++', 'Golang', 'Java', 'Python', 'Swift'], dtype=object)`
Index tùy chỉnh giúp dữ liệu dễ đọc hơn và phù hợp với ngữ cảnh sử dụng.

### **Lấy giá trị trong Series (Get Rows)**
Có nhiều cách để truy cập giá trị:
**1. Truy cập bằng chỉ số (index vị trí)**
```Python
print(data[0])  # 5
print(data[1])  # 7
```
  
|Lệnh|Giá trị|
|---|---|
|data[0]|5|
|data[1]|7|
|data[2]|5|
|data[3]|1|
|data[4]|6|
**2. Truy cập bằng** `**.loc[]**` **(theo nhãn index)**
```Python
print(data.loc[0])  # 5
print(data.loc[1])  # 7
```
Cú pháp này dùng cho **label-based indexing** (theo tên index).
  
**3. Lấy nhiều hàng liên tiếp**
```Python
result = data.loc[2:3]
```
**Output:**
|Index|Value|
|---|---|
|2|5|
|3|1|
**4. Lấy nhiều hàng theo vị trí (slicing)**
```Python
result = data[2:3]
```
**Output:**
|Index|Value|
|---|---|
|2|5|
**5. Lọc theo điều kiện giá trị**
```Python
result = data[data.between(3, 6)]
```
**Output**
|Index|Value|
|---|---|
|0|5|
|2|5|
|4|6|
```Python
result = data[data > 5]
```
  
Output
|Index|Value|
|---|---|
|1|7|
|4|6|
- **Câu hỏi gợi mở**
    - Khi nào nên dùng `.loc[]` và khi nào dùng slicing `[start:end]`?
        - **Dùng** `**.loc[]**` khi bạn muốn truy cập **theo nhãn index** (label-based indexing).
            
            Ví dụ: nếu index là `'A', 'B', 'C'`, thì `data.loc['A']` sẽ lấy đúng giá trị có nhãn `'A'`.
            
            `.loc[start:end]` **bao gồm cả** `end` khi slicing.
            
        - **Dùng slicing** `**[start:end]**` khi bạn muốn truy cập **theo vị trí** (position-based indexing) hoặc khi index là số mặc định từ 0.
            
            Ví dụ: `data[0:3]` sẽ lấy phần tử ở vị trí 0, 1, 2 (**không bao gồm** vị trí 3).
            
    - Làm thế nào để lấy đồng thời các giá trị có index cụ thể (ví dụ `[0, 2, 4]`)?
        
        Cách 1: Dùng `.loc[]` (theo nhãn index). Ví dụ: `result = data.loc[[0, 2, 4]]`
        
        Cách 2: Dùng `.iloc[]` (theo vị trí). Ví dụ: `result = data.iloc[[0, 2, 4]]`

## 2. 1D interpolation
**Giới thiệu bài toán nội suy:**
Cho hai điểm dữ liệu đã biết **(x₁, y₁)** và **(x₂, y₂)**, cần tìm giá trị y tại các vị trí trung gian **u, v, p, q** trên trục x.
  
![[image 6 16.png|image 6 16.png]]
### Phương pháp 1 – Nearest Neighbor (Láng giềng gần nhất)
**Ý tưởng:**
- Với mỗi điểm cần tìm (u, v, p, q), tính khoảng cách đến **x₁** và **x₂**.
- Chọn giá trị y của điểm dữ liệu **gần hơn**.
**Đặc điểm:**
- Dễ tính toán.
- Tạo ra đường nội suy **bậc thang** (step-like), không trơn tru.
- Không phù hợp khi yêu cầu độ mượt cao.
![[image 7 13.png|image 7 13.png]]
**Công thức:**
```R
y(u) = y₁ nếu |u - x₁| < |u - x₂|, ngược lại y₂
```
---
### Phương pháp 2 – Linear Interpolation (Nội suy tuyến tính)
**Ý tưởng:**
- Nối thẳng hai điểm **(x₁, y₁)** và **(x₂, y₂)**.
- Giá trị y tại các vị trí trung gian được xác định theo tỷ lệ khoảng cách.
**Đặc điểm:**
- Kết quả mượt và liên tục.
- Dễ áp dụng cho dữ liệu biến đổi tuyến tính giữa các điểm.
![[image 8 13.png|image 8 13.png]]
**Cách làm:**
Giả sử ta có hai điểm:
- $A(x_1, y_1)$
- $B(x_2, y_2)$
Phương trình đường thẳng:
$$y = a x + b \tag{1}$$
Xác định hệ số góc $\alpha$. Từ hai điểm A và B:
$$a = \frac{y_2 - y_1}{x_2 - x_1} \tag{2}$$
Xác định tung độ gốc $b$. Thay điểm A vào (1):
$$b = y_1 - \frac{y_2 - y_1}{x_2 - x_1} x_1 \tag{3}$$
Thay (2) và (3) vào (1):
$$y = \frac{y_2 - y_1}{x_2 - x_1} x + \left( y_1 - \frac{y_2 - y_1}{x_2 - x_1} x_1 \right) \tag{4}$$
Biến đổi thu gọn:
$$y = \frac{x_2 - x}{x_2 - x_1} y_1 + \frac{x - x_1}{x_2 - x_1} y_2$$
Gọi:
$$\alpha = \frac{x_2 - x}{x_2 - x_1}$$
$$1 - \alpha = \frac{x - x_1}{x_2 - x_1}$$
Từ đó ta có Công thức nội suy tuyến tính:
$$y = \alpha y_1 + (1 - \alpha) y_2$$
![[image 9 12.png|image 9 12.png]]
---
- **Nearest neighbor** nhanh và dễ nhưng không mượt, phù hợp khi dữ liệu là giá trị rời rạc, không cần tính liên tục.
- **Linear interpolation** phù hợp hơn khi dữ liệu thay đổi dần đều.
**Ví dụ bài toán**
Cho bảng giá trị $f(x)$ với $x = 0, 1, 2, \dots, 7$ , trong đó một số giá trị bị thiếu (`None`). Cần tìm giá trị tại $x = 2$ dựa trên 2 điểm lân cận:
- $(1, 2.2)$
- $(3, 2.7)$
![[image 10 11.png|image 10 11.png]]
**1. Nearest Neighbor Interpolation**
Khoảng cách từ $x=2$ đến:
- $x_1 = 1$: khoảng cách = 1
- $x_2 = 3$: khoảng cách = 1
Trường hợp bằng nhau, thường **chọn giá trị bên trái** (hoặc theo quy tắc định sẵn).
**Kết quả:**
$$f(2) = 2.2$$
  
**2. Linear Interpolation**
**Công thức:**
$f(x) = y_1 + \frac{x - x_1}{x_2 - x_1} \cdot (y_2 - y_1)$
Thay:$x_1 = 1, \quad y_1 = 2.2$$x_2 = 3, \quad y_2 = 2.7$$x = 2$
Tính:$f(2) = 2.2 + \frac{2 - 1}{3 - 1} \cdot (2.7 - 2.2)$$f(2) = 2.2 + 0.5 \cdot 0.5 = 2.45$
**Kết quả:**$f(2) = 2.45$

## 4. Noise Reduction
Khi làm việc với dữ liệu chuỗi thời gian (time series), đặc biệt là dữ liệu nhiệt độ, tốc độ gió, độ ẩm… thường tồn tại **nhiễu** – các dao động ngẫu nhiên không mang thông tin xu hướng.
Giảm nhiễu (Noise Reduction) giúp:
- Làm mượt đường biểu diễn.
- Dễ quan sát xu hướng dài hạn.
- Giảm tác động của biến động đột ngột (outlier) tới mô hình học máy.
### Moving Average – Trung bình trượt
**SMA (Simple Moving Average):**
$$SMA_t = \frac{s_t + s_{t-1} + \dots + s_{t-k+1}}{k}$$
- **SMA (Simple Moving Average):** Lấy trung bình của **k** giá trị gần nhất.
  
**EMA (Exponential Moving Average):**
$$EMA_t = \rho \cdot EMA_{t-1} + (1 - \rho) \cdot s_t$$
- Gán trọng số lớn hơn cho các giá trị mới hơn.
- Ít bị trễ (lag) so với SMA.
**Ví dụ:**
```Python
data_sma = data.rolling(window=5).mean()
```
- `window=5`: lấy trung bình của 5 điểm liên tiếp.
- Kết quả: đường biểu diễn mượt hơn, giảm các dao động nhỏ.

## 2. Example 1: Weather dataset
Quay lại với dữ liệu nhiệt độ ở phần 1 đã giới thiệu.
- Dữ liệu thời gian (`datetime`) được giữ nguyên dạng chuỗi '2006-12-01 00'
    
    → Mô hình Machine Learning không thể hiểu ý nghĩa trực tiếp của chuỗi thời gian này (chuỗi ký tự không có quan hệ số học rõ ràng).
    
- `datetime` được tách thành nhiều **feature số học**:
    
    - `year = 2006`
    - `month = 12`
    - `day = 1`
    - `hour = 0`
    
    → Mô hình dễ học hơn, vì các giá trị này là **dữ liệu dạng số** và thể hiện trực tiếp các đặc trưng thời gian.
    
### Datatime
**Cấu trúc datetime**
```SQL
year-month-day hour:minute:second.millisecond
```
Trong Pandas, có thể truy cập từng thành phần qua:
```SQL
datetime = pd.to_datetime('2006-12-01 00:00:00.000')
print(datetime)        \#2006-12-01 00:00:00
print(datetime.year)   #2006
print(datetime.month)  #12
print(datetime.day)    #1
print(datetime.hour)   #0
```
**Chuyển đổi cột ngày giờ sang kiểu datetime**
- Cột `'Formatted Date'` được chuyển sang kiểu **datetime64[ns, UTC]** để dễ thao tác với thời gian.
- `utc=True` đảm bảo dữ liệu được chuẩn hóa theo múi giờ UTC.
**Tách các thành phần thời gian:**
- `.dt.year` → Lấy năm.
- `.dt.month` → Lấy tháng.
- `.dt.day` → Lấy ngày.
- `.dt.hour` → Lấy giờ.
- Giúp phân tích dữ liệu theo từng thành phần thời gian hoặc xây dựng mô hình dự báo theo các yếu tố này.
Sau đó xóa cột gốc `Formatted Date`
```Python
df = pd.read_csv('weatherHistory2D.csv')
```

### Delete a row
```Python
df.drop(label, axis)
```
- `**axis=0**` → xóa **dòng** (row) theo **index**
- `**axis=1**` → xóa **cột** (column) theo **tên cột**
Xóa 1 dòng
```Python
df.drop(1, axis=0)  
```
→ Xóa dòng có **index = 1**.
  
Xóa 2 dòng
```Python
df.drop([1, 2, 3], axis=0)
```
→ Xóa các dòng có **index = 1, 2, 3**.
---
### Delete a column
Xóa 1 cột
```Python
df.drop('Radio', axis=1)
```
→ Xóa cột **Radio**.
Xóa nhiều cột
```Python
df.drop(['Radio', 'Sales'], axis=1)
```
→ Xóa cột **Radio** và **Sales**.
**Ví dụ:**
Trong xử lý dữ liệu NLP, thường **id**, **keyword**, và **location** không cần thiết cho bước tiền xử lý văn bản, nên ta sẽ xóa chúng.
```Python
import pandas as pd
# Đọc dữ liệu từ file CSV
df = pd.read_csv("path_to_cvs_file")

df.drop(["id", "keyword", "location"], axis=1, inplace=True)
```
